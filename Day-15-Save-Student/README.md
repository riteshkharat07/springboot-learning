# Day 15 - Save Student

## 📌 Objective

Learn how to save student data into the MySQL database using Spring Data JPA.

## 📚 Topics Covered

- POST API
- @RequestBody
- JpaRepository.save()
- Controller
- Service
- Repository

## 🛠 Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- MySQL

## API

POST /student

## Sample Request

{
    "name":"Ritesh",
    "city":"Akola"
}

## Response

Student Saved Successfully

## ✅ Outcome

Successfully inserted student data into MySQL.
