# Day 01 - Spring Boot Project Setup

## 📌 Objective

Learn how to create and run a Spring Boot project.

## 📚 Topics Covered

- Spring Initializr
- Maven Project
- Dependencies
- Project Structure
- Main Application Class
- Running Spring Boot Application

## 🛠 Tech Stack

- Java 21
- Spring Boot
- Maven
- IntelliJ IDEA

## 📂 Project Structure

```
src
 ├── main
 │   ├── java
 │   └── resources
 └── test
```

## ▶️ Run Application

Run the main class:

```
DemoApplication.java
```

Application will start on:

```
http://localhost:8080
```

## ✅ Outcome

Successfully created and executed my first Spring Boot project.
