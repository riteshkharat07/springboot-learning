# Day 19 - Delete Student

## 📌 Objective

Learn how to delete a student record using JpaRepository.deleteById().

## 📚 Topics Covered

- DELETE API
- @PathVariable
- JpaRepository.deleteById()

## 🛠 Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- MySQL

## 🌐 API

### Method

DELETE

### URL

http://localhost:8080/student/1

### Response

```text
Student Deleted Successfully
```

## ✅ Outcome

Successfully deleted a student record from the database.
