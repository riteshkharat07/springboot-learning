# Day 13 - @Entity, @Table, @Id

## 📌 Objective

Learn how to map a Java class to a MySQL table using JPA annotations.

## 📚 Topics Covered

- @Entity
- @Table
- @Id
- @GeneratedValue

## 🛠 Tech Stack

- Java
- Spring Boot
- MySQL
- Spring Data JPA

## ✅ Outcome

Created the first JPA Entity and mapped it with the MySQL table.
