# Day 16 - Get All Students

## 📌 Objective

Learn how to fetch all student records from the MySQL database using JpaRepository.findAll().

## 📚 Topics Covered

- GET API
- JpaRepository.findAll()
- List<Student>

## 🛠 Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- MySQL

## API

GET /student

## Response

Returns all student records.

## ✅ Outcome

Successfully fetched all students from the database.
