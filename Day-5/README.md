# Day 05 - @PostMapping

## 📌 Objective

Learn how to use @PostMapping to send data from the client to the server.

## 📚 Topics Covered

- @PostMapping
- @RequestBody
- POST Request
- JSON Data

## 🛠 Tech Stack

- Java
- Spring Boot

## 💻 API

POST /student

## Sample JSON

```json
{
  "id": 101,
  "name": "Ritesh",
  "city": "Nashik"
}
```

## ✅ Response

Student Added Successfully
