# Day 06 - @PutMapping

## 📌 Objective

Learn how to update existing data using @PutMapping.

## 📚 Topics Covered

- @PutMapping
- @RequestBody
- Update API
- PUT Request

## 🛠 Tech Stack

- Java
- Spring Boot

## 💻 API

PUT /student

## Sample JSON

```json
{
  "id": 101,
  "name": "Ritesh Kharat",
  "city": "Pune"
}
```

## ✅ Response

Student Updated Successfully
