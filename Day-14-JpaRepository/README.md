# Day 14 - JpaRepository

Learn how to use JpaRepository to perform CRUD operations without writing SQL queries.

## 📚 Topics Covered

- JpaRepository
- save()
- findAll()
- findById()
- deleteById()
- count()
- existsById()

## 🛠 Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- MySQL

## ✅ Outcome

Learned how JpaRepository provides built-in CRUD methods.
