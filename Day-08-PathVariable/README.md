# Day 08 - @PathVariable

## 📌 Objective

Learn how to pass values in the URL using @PathVariable.

## 📚 Topics Covered

- @PathVariable
- Dynamic URL
- GET Request
- URL Parameters

## 🛠 Tech Stack

- Java
- Spring Boot

## 💻 API

GET /student/{id}

Example:

GET /student/101

## Response

Student ID : 101

## ✅ Outcome

Learned how to retrieve values directly from the URL using @PathVariable.
